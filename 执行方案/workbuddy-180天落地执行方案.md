> 版本：v1.0（2026-09-26）
> 使用方式：每周日复盘时对照本方案勾选，向教练汇报进度。
> 总原则：**知识 → 项目 → GitHub → 内容 → 求职能力**，每一步都要留下公开证据。

## 三、阶段1：LLM 应用 + RAG 筑基（Day 15-45）

**目标**：吃透 JD 里出现频率最高的技能——RAG 全链路，并且留下可演示证据。

### Week 3 · Prompt 工程
- 学习：结构化输出、JSON Schema、few-shot、System Prompt 设计、提示词注入防护
- 项目：Prompt 模板库（10 个求职场景模板，版本化管理）
- 内容：《Prompt 不是聊天，是接口设计——Java 程序员的理解方式》

### Week 4 · 大模型接入进阶
- 学习：SSE 流式输出、多轮会话管理、上下文窗口、Token 成本统计
- 项目：命令行 Chat 工具 v2（流式 + 会话历史 + 每次调用计价）
- 内容：《我给自己做了个 Token 计价器，一个月 API 花了 XX 元》（有数据）

### Week 5 · RAG 基础
- 学习：文档解析、切分策略、Embedding 选型、向量库（Milvus 或 pgvector 选一个）
- 项目：RAG v1——本地 Markdown 文档问答
- 内容：《RAG 全链路一张图：从 PDF 到答案经过了几道工序》

### Week 6 · RAG 进阶
- 学习：混合检索（关键词+向量）、Rerank、引用溯源、无依据拒答
- 项目：RAG v2，对比 v1 回答质量
- 内容：《为什么你的 RAG 在胡说八道：我测了 3 种切分策略》（有实验）

### Week 7 · 评测体系 + 阶段收口
- 学习：Golden Dataset、召回率/正确率评测、LLM-as-Judge
- 项目：给 RAG v2 加评测脚本，输出评测报告
- 内容：《我给 AI 出了 50 道题考试：评测集怎么做》
- **里程碑检查**：技能地图 v1 更新为 v2（标注已掌握/未掌握）

**验收标准**：RAG v2 仓库（含评测报告）；能画出并讲清 RAG 全链路；小红书累计 ≥10 条，粉丝 ≥300。
**失败信号**：项目能跑但讲不出取舍理由 → 停止学新东西，回头补原理。

## 四、阶段2：Agent + MCP + 工程化（Day 46-80）

**目标**：做出旗舰项目「JD-简历匹配诊断器」，这是求职作品集 + IP 内容 + 未来产品的三位一体资产。

### Week 8 · Agent 核心
- 学习：ReAct、Planning、Memory、多步任务拆解；LangChain4j AI Services / Agent 能力
- 项目：单 Agent 原型——"帮我分析这个 JD 并给出准备建议"
- 内容：《Agent 和 Chatbot 的区别，我用一个例子讲清楚》

### Week 9 · MCP
- 学习：MCP 协议原理、接入一个公开 MCP Server、写一个自己的 MCP Server
- 项目：给 Agent 接上 MCP 工具
- 内容：《MCP 为什么出现在 2026 年的 JD 里：我上手试了一周》

### Week 10 · AI 工程化
- 学习：模型适配层（多模型切换/超时/限流/熔断/降级/成本统计）、与微服务体系集成
- 项目：给自己的项目加适配层
- 内容：《把大模型当微服务治理：限流、熔断、降级一套带走》

### Week 11-12 · 旗舰项目
- 项目：**JD-简历匹配诊断器 MVP**
  - 输入：目标 JD 文本 + 简历文本
  - 输出：匹配度评分、技能差距清单、按周的学习路径建议
  - 技术：Spring Boot + Spring AI/LangChain4j + RAG（JD 库）+ 结构化输出
  - 前端：极简页面（Thymeleaf 或简单 Vue 均可，不追完美）
- 上线：服务器部署 + 录 60 秒演示视频
- 内容：《我用 30 天给自己做了个求职诊断器（附开源地址）》—— B站长视频 + 小红书图文同步

**验收标准**：诊断器公网可访问；README 含架构图+演示；能完整讲清技术选型理由；粉丝 ≥800。
**失败信号**：MVP 做了两周还在调 UI → 砍掉非核心页面，先上线再迭代。

## 五、阶段3：求职冲刺（Day 81-120）——与 IP 并行

**目标**：拿到 Offer。此阶段内容线降为每周 1-2 条，全部取材于真实求职过程。

### Week 13 · 简历重写
- 两版简历：A 版投「Java+AI 应用开发」，B 版投「AI 平台/Agent 工程」
- 核心写法：StarWing 量化成果 + 3 个 AI 项目（RAG / Agent / 诊断器）+ 技能地图自评
- 内容：《我的简历被自己的 AI 诊断后，改了 11 处》

### Week 14 · 面试备战
- 知识图谱：Java 八股（JVM/并发/集合）+ AI 专项（RAG 调优/Agent 设计/评测/成本控制）
- 用诊断器 + Prompt 模板做模拟面试，每天 30 分钟自问自答录音
- 准备 3 分钟自我介绍话术（Java 背景 → AI 转型 → 项目证据）

### Week 15-16 · 第一批投递（20 家）
- 5 家练手公司先投 → 攒面试经验；再投 15 家匹配公司
- 渠道：BOSS 直聘为主 + 脉脉/掘金/朋友圈求内推
- 每次面试 24h 内写复盘（问题清单 + 答得差的点）
- 内容：《第一次 AI 岗面试我挂了，复盘如下》（真实失败，不虚构）

### Week 17-18 · 第二批投递（30 家）+ Offer 谈判
- 根据复盘补丁式补弱项
- 薪资谈判锚定 20-25K，用项目证据支撑
- 内容：《投递 50 次、面试 X 场，我的 Java 转 AI 数据报告》

**验收标准**：≥1 个 Offer 或 ≥3 个终面。
**失败信号（触发 Plan B）**：投递 50 家面试 <5 场 → 简历问题，回炉；面试 10 场 0 终面 → 表达/项目深度问题，加 2 周专项训练后再投。

## 六、阶段4：产品 MVP + IP 加速（Day 121-150）

**前提判断**：已拿 Offer → 主线转产品与 IP；未拿 Offer → 求职冲刺延长，本阶段减半执行。

### 每周固定节奏（W19-22）
| 线 | 任务 |
|----|------|
| 产品 | 诊断器加：用户历史记录、结果分享卡片（裂变）、反馈入口；招募 **10 个种子用户**（粉丝+掘金+朋友圈）免费深度服务，换使用反馈和授权案例 |
| 内容 | 周更 2-3 条；开新系列：《我帮粉丝诊断简历》第 1-4 期（脱敏后发布） |

| 求职 | 已上岸：写入职准备清单；未上岸：继续 Plan B 冲刺 |

**验收标准**：10 个种子用户完成全流程；沉淀 ≥3 个可公开案例（脱敏+授权）；粉丝 ≥2000。
**失败信号**：种子用户用完不说话 → 产品没解决真痛点，做 5 个用户访谈找原因，不要闷头加功能。

## 八、贯穿 180 天的铁律

1. **每周日晚 30 分钟复盘**，对照本方案勾选，向教练按格式汇报。
2. **任何学习必须 72h 内变成**：代码提交 / 内容 / 笔记，三选一。
3. **内容取材只来自真实过程**，数据不虚构，失败照发。
4. **任何一个任务拖期 >2 周**，不是延期，是砍掉或降级——计划为结果服务。
5. **每 30 天校准一次方向**：技能地图 vs JD 变化、内容数据 vs 选题、产品反馈 vs 功能清单。
